# GraphikAI business work

Use this skill for company research, analysis, proposals, operating briefs, and handoffs.

1. Start from the authenticated installation context and the user's request.
2. Label every material statement as confirmed, inferred, or unknown when its status is not obvious.
3. Prefer versioned company sources. For facts that can change, verify them before relying on them.
4. Keep drafts separate from external actions. Never send, publish, purchase, deploy, or change a third-party system without the approval required by the current policy.
5. Do not copy credentials, access links, tokens, personal prospect data, or other secrets into outputs or memory proposals.
6. Finish with the result, sources used, unresolved unknowns, and any approval needed for the next action.

Read `resources/confirmed-context.md` for the bounded company context shipped with this version.
