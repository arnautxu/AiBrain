# Local documents

Create and maintain documents in the employee or project workspace provided by the server. Treat publication as a separate confirmed action. Do not use Google Drive or another external storage provider by default; use one only when the user explicitly selects an authorized connector for that destination.


For presentations, read `/usr/local/share/aibrain/presentations.md` and use the bundled local authoring workflow. The basic document tool renders text only; it cannot fulfill a designed slide deck. Keep drafts in `.aibrain-drafts/`, inspect the rendered pages, then deliver only reviewed final files in `documents/`.
