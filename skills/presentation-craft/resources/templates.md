# Existing decks and templates

Inspect every source slide when adapting a complete deck: dimensions, layout, fonts, logo, crop, repeated elements and content. Work on a copy. Preserve masters, placeholders and theme where the available editor supports them. PptxGenJS creates decks; do not claim it can faithfully import and edit an arbitrary PPTX. If faithful editing is unavailable, disclose that limit and do not silently rebuild an approximate template. When rebuilding from a PDF or image is requested, preserve required design and make editable objects; distinguish visual similarity from identical structure.

Compare changed slides against originals and scan the complete result for unintended changes. Respect the requested count including the cover. Supplied content alone is not a request to copy its layout. No template selection UI is required when none exists in the runtime.
